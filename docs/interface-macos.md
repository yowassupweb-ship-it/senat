# Senate: интерфейс в стиле macOS

Дата: 11 ноября 2026.

Рабочее приложение для постоянных цифровых специалистов. Направление: спокойное настольное рабочее пространство — нейтральные поверхности, системный шрифт, синий акцент, компактные элементы управления, короткие анимации. Сохранены маршруты, API и существующие функции.

## Что изменилось

- Общие темы вынесены в `ui/tokens/theme.json`; `npm run theme:build` генерирует `src/theme.css`. Сборка запускает генерацию автоматически.
- Переработаны боковая панель, выбранные разделы, заголовки, чат, поле сообщения, карточки, формы, меню и диалоги. Светлая и тёмная темы используют один набор семантических переменных.
- Добавлены статус соединения, подсказка Enter / Shift+Enter, сочетание Ctrl/Cmd + запятая для настроек. Выбранные разделы и переключатели получили доступные состояния.
- На узком окне навигация открывается отдельной панелью; основной экран временно недоступен для фокуса. Escape закрывает панель, фокус возвращается к кнопке открытия.
- Выпадающие списки поддерживают стрелки, Home, End, Escape, выбор с клавиатуры и размещение внутри окна. Диалоги удерживают фокус и возвращают его после закрытия.
- Ошибка отправки сохраняет черновик. Ожидание отправки блокирует повторный запрос; успешная отправка очищает черновик. Исправлена позиция курсора при повторном @упоминании.
- Подключение показывает ожидание и позволяет повторить попытку после ошибки. Сохранённая тема применяется до запуска приложения, чтобы уменьшить вспышку другой темы.

## Найденные и устранённые проблемы

| Приоритет | Проблема | Исправление |
|---|---|---|
| Высокий | Текст исчезал до подтверждения отправки | Очистка только после успешного ответа |
| Высокий | Меню не управлялись стрелками; фокус выходил из диалога | Навигация по вариантам и общая функция focusScope |
| Высокий | Боковая панель и сетки обрезали интерфейс узкого окна | Выдвижная навигация, переносы и гибкие минимальные размеры |
| Средний | Недостаточный контраст вторичного текста и статуса ошибки | Коррекция общих цветовых токенов |
| Средний | Неявный выбор разделов и разрозненное оформление | Общие поверхности, состояния выбора и отступы |

## Проверка

- `npm run check`: 0 ошибок, 0 предупреждений.
- `npm run build`: успешно; результат в `ui/dist`.
- `npm run test:ui`: 6 тестов прошли, без пропусков.
- Проверены 9 маршрутов в светлой и тёмной темах: чат, специалисты, проекты, компании, задачи, память, MCP, API, настройки.
- Проверено отсутствие горизонтального переполнения страницы и выхода контролов основного экрана за границы при ширинах 280, 320, 414 и 1440 px.
- axe-core не выявил нарушений в проверенных состояниях по наборам WCAG 2 A/AA и 2.1 AA. Отдельно проверены открытый список, диалог форума и состояния hover/focus в обеих темах.
- Проверены клавиатурный выбор, Escape и возврат фокуса, мобильный переход, ошибка и успех отправки, защита от дублирования и повтор подключения.
- Снимки просмотрены: `docs/interface-preview/`.

Тесты используют изолированные ответы API. Это проверка интерфейса, а не сертификация доступности и не проверка всех вариантов рабочих данных. Реальные провайдеры, отправка запросов моделям, интеграции и нативная оболочка Tauri в этом прогоне не запускались. Исполняемый файл desktop не пересобирался; готова веб-сборка, которую использует сервер Senate. На сервер изменения не публиковались.

## Повторить проверку

Из `ui`: `npm install`, `npx playwright install chromium`, `npm run check`, `npm run build`, `npm run test:ui`, `node scripts/accuracy_report.mjs`.

При необходимости задать путь к уже установленному Chromium через `SENATE_TEST_BROWSER`. Полный машинный отчёт: `ui/test-results/results.json`. Резервная копия исходного интерфейса: `docs/ui-backup/src`.

В установленном наборе design skills отсутствуют упомянутые им вспомогательные workflows и скрипты проверки. Вместо них добавлены воспроизводимые проверки Playwright и axe-core в самом проекте.
