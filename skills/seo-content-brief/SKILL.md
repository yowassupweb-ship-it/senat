# ТЗ на SEO-текст

ТЗ пишет SEO-специалист, текст пишет копирайтер, проверяет SEO-специалист. Одно ТЗ — одна страница — один кластер.

## 1. Данные до ТЗ

- Кластер запросов с частотностью (Вордстат, Topvisor, данные SEO Wizard в MBOX). Не придумывать запросы из головы.
- Интент кластера: информационный («что посмотреть в Казани»), коммерческий («тур в Казань на 3 дня»), навигационный. Смешанный кластер — разделить на разные страницы.
- Каннибализация: нет ли на сайте страницы, которая уже ранжируется по этим запросам (SEO Wizard). Если есть — улучшать её, а не писать новую.
- Топ-10 выдачи по главному запросу: какие типы страниц там стоят, какие разделы есть у всех, чего нет ни у кого (там наш шанс).

## 2. Шаблон ТЗ

```markdown
# ТЗ: <страница>, URL: <адрес или «новая»>

Цель страницы: что человек должен сделать (выбрать тур, оставить заявку, узнать ...).
Интент: ...
Главный запрос: ... (частотность)
Дополнительные запросы: список с частотностью; употребить по смыслу, не обязательно в точной форме.

Title (до 60 знаков): черновик
Description (до 160 знаков): черновик, с выгодой и призывом
H1: черновик (не копия Title)

Структура:
- H2 ... — о чём раздел, какие факты обязательны
- H2 ...
- H2 Частые вопросы — 4–6 вопросов из подсказок выдачи и «Люди также спрашивают»

Объём: ориентир по топу (медиана), не догма.
Обязательные факты и источники: цены, даты, длительность — только с сайта и из MBOX.
Перелинковка: на какие страницы сайта сослаться и с какими анкорами.
Разметка: FAQPage, Product/Offer или TouristTrip — что применимо.
Нельзя: переспам (точное вхождение главного запроса не чаще 2–3 раз), выдуманные факты, тексты «для робота».
```

## 3. GEO: чтобы страницу цитировал ИИ-поиск

- Первый абзац под H1 — прямой ответ на главный запрос в 2–3 предложениях, без вступлений.
- Конкретика, которую можно процитировать: цифры, сроки, что входит в стоимость, маршрут по дням.
- Разделы с вопросом в заголовке и ответом в первой фразе.
- Дата актуальности цен и программы на странице.

## 4. Приёмка текста

Проверить по ТЗ: все разделы есть, факты сверены с источником, Title/Description в лимитах, главный запрос в H1 и первом абзаце, нет переспама, ссылки расставлены. Замечания — списком с цитатой места, а не «переписать».
